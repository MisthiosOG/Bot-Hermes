FAQ

Pertanyaan yang
sering diajukan.

Masih ragu? Mungkin jawabannya ada di sini.

Berapa lama setup-nya?
1-3 menit setelah pembayaran diverifikasi. Sistem otomatis deploy panel Hermes Gateway + domain publik. Kamu tinggal tunggu kredensial masuk ke Telegram.
API key LLM-nya dari mana?
Kamu isi sendiri di dashboard setelah login. Bisa pakai OpenRouter (gratis untuk beberapa model), Anthropic, DeepSeek, Gemini, Grok, dan 20+ provider lainnya. Kamu yang pegang API key-nya.
Ini VPS atau apa?
Bukan VPS biasa. Ini panel AI agent self-hosted yang berjalan di infrastructure cloud terkelola. Kamu dapet admin dashboard web + SSH root access ke instance sendiri. Beneran punya kendali penuh.
Kredensial dikirim ke mana?
Langsung ke Telegram kamu (pastikan udah /start bot) dan muncul juga di dashboard halaman ini.
Bisa ganti password?
Bisa. Login ke panel admin, buka menu Settings, ada opsi ganti password admin dan SSH. Ganti kapan aja sesuai keinginan.
Kalau ada masalah?
Hubungi admin via Telegram. Kami bantu troubleshooting sampe agent kamu berjalan. Garansi setup berhasil atau refund.
